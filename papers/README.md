# Papers

This directory contains manuscript source associated with research developed in this repository.

Each paper lives in its own subdirectory and should be self-contained enough to build independently.

## Current manuscripts

- [`failure-aware-multimodal-behavioural-sensing/`](failure-aware-multimodal-behavioural-sensing/) — methodological paper on failure-aware multimodal behavioural sensing, probabilistic state inference, person attribution, and sensor reduction.
- [`when-confidence-is-not-information/`](when-confidence-is-not-information/) — development-panel study of whether posterior confidence, margin, entropy, evidence strength, or information gain ranks prediction correctness, analysed under a contract frozen before execution.
