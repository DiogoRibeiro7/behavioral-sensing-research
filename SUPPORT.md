# Support

Use the channel that best matches the request.

## Bug Reports

Open a GitHub issue using the bug report template:

<https://github.com/DiogoRibeiro7/behavioral-sensing-research/issues/new/choose>

Include a minimal reproduction, environment details, and relevant test output.

## Feature Requests and Research Ideas

Use GitHub issues for concrete feature requests and GitHub Discussions for
open-ended research ideas:

- Issues: <https://github.com/DiogoRibeiro7/behavioral-sensing-research/issues>
- Discussions: <https://github.com/DiogoRibeiro7/behavioral-sensing-research/discussions>

## Security Reports

Do not report vulnerabilities in public issues. Follow `SECURITY.md` and email
the maintainer privately.

## Clinical and Research Use

This project is a research toolkit. It is not a medical device and should not be
used as the sole basis for clinical decisions. When asking for support with
clinical or sensitive behavioral data, remove personal identifiers and share
only the smallest reproducible example.
